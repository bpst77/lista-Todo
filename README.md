## 📌 Sobre o Projeto

O presente projeto tem como objetivo o desenvolvimento de uma aplicação web com o uso do framework 'React' do Node.js(Javascript) com a implementação de CRUD.

Este projeto foi desenvolvido como requisito para composição de nota.

## 🛠️ Detalhes

* **Framework React+vite** *+Lucide/Framer motion*
* **Postcss** *+Tailwindcss*
* **MockAPI**

## 🎯 Escopo e Funcionalidades Previstas

O aplicativo contempla:

* **Lita de afazeres:** tarefas pessoais a serem completadas.

* **CRUD:** Possibilidade de editar os dados.
* **API online:** MockAPI.
